# SNCF-modell: Statens netto kontantstrøm fra petroleumsvirksomheten

Statisk scenariomodell (3x3) og Monte Carlo-simulering (Excel-nativ) av
statens netto kontantstrøm 2026-2050, i faste 2026-kroner.

Hovedleveranse: `Kontantstromsmodell_petroleum.xlsx` (selvforsynt — åpnes
og brukes i ren Excel; parametre endres i Forutsetninger-arket B4-B15).

Se `CLAUDE.md` for full modelldokumentasjon, beslutningslogg,
verifikasjoner og arbeidsregler.
